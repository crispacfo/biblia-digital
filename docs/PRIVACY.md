# Privacidade

Bíblia Digital processa a leitura, busca e exibição bíblica localmente no WordPress.

## Dados de visitantes

- O plugin não coleta dados pessoais de visitantes.
- O plugin não rastreia visitantes.
- O plugin não cria cookies próprios.
- O plugin não envia consultas, páginas acessadas ou dados de visitantes para terceiros.

## Dados administrativos

- Bíblias importadas pelo administrador ficam armazenadas no banco de dados local do WordPress.
- Arquivos de tradução enviados pelo administrador podem ser salvos em `wp-content/languages/plugins` ou na pasta `languages` do plugin quando necessário.
- Logs e mensagens administrativas são armazenados em opções locais do WordPress.

## Serviços externos

O plugin não depende de chamadas remotas obrigatórias para funcionar. Qualquer link externo configurado pelo administrador é opcional.

## Responsabilidade sobre conteúdo importado

O pacote público não distribui base bíblica nativa em SQL nem traduções bíblicas protegidas. O administrador do site é responsável por garantir que Bíblias, traduções e arquivos enviados tenham licença adequada para uso no site.
